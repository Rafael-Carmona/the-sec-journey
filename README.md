# the-sec-journey 🚀  
> A jornada prática de segurança do Rafael

Bem-vindo ao meu laboratório pessoal de segurança da informação. Este repositório é **minha jornada em andamento**: aqui eu aprendo, testo e documento tudo na prática. Cada pasta é um capítulo que vai crescendo conforme eu resolvo desafios, faço labs e registro meus aprendizados.

---

## O que você vai encontrar aqui

- **DesafiosSec/** — meus desafios CTF e labs, documentados com passo a passo, scripts e evidências.

- **Scan/** — script, ainda terá varreduras de rede e testes práticos.

> ⚠️ Observação: tudo é feito em **ambiente de laboratório**. Todos os dados são fictícios.

- **Em evolução**: novos desafios e notas vão sendo adicionados conforme eu estudo e pratico.
