## Descrição
Recebemos registros (access logs) de um servidor web que sofreu uma tentativa de ataque. Seu objetivo é analisar os logs e responder às perguntas para entender o que aconteceu — quem atacou, como tentou atacar e qual recurso tentou acessar.

## Objetivo
Responder corretamente às perguntas abaixo usando apenas os logs fornecidos.

## Perguntas
1. **Qual é o IP do atacante?**  
2. **Qual é o tipo de ataque?**  
3. **Qual foi a entrada (endpoint) que o atacante tentou acessar?**
