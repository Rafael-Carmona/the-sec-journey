# Solução do Desafio Password 

## Passo a passo da solução: 
- Acesse a página web fornecida pelo desafio (a URL do desafio).
- Clique com o botão direito na página e escolha **Inspecionar**; ou use o atalho do navegador (ex.: **F12** ou **Ctrl+Shift+I**).
- Examine o painel *Elements* buscando comentários HTML  
Comentários aparecem no formato:
```html
<!-- ... -->
```
