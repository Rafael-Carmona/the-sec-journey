# Logs
**Nível:** Iniciante  
**Pontuação:** 15 pontos  
**Plataforma:** HackersHack  

## Descrição
Recebemos os logs de acesso de um servidor web que sofreu uma tentativa de invasão. Sua missão é analisar esses registros e responder às perguntas para entender o que aconteceu.


## Objetivo
Responder corretamente às perguntas abaixo para entender o ataque e pontuar.

## Perguntas:
1. Qual é o IP do atacante?
2. Qual é o tipo de ataque?
3. Qual foi a entrada que o atacante tentou acessar?
