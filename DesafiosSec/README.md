# DesafiosSec — Coleção de Desafios de Segurança

> ⚠️ Todos os desafios aqui foram realizados em **ambiente de laboratório**. Todos os dados são fictícios.

Este diretório é o meu **repositório de desafios de segurança**, onde documento e organizo tudo que resolvo na prática. Cada pasta representa uma **origem ou plataforma de desafios**, e dentro de cada uma você encontra os desafios completos, com `README.md` individual, passo a passo em `solucao.md`, scripts e evidências.

---

## Como navegar

1. Abra a pasta da origem do desafio (ex.: `Hackersec/`).  
2. Cada pasta de desafio dentro contém:  
   - `README.md` — resumo do desafio e informações básicas.  
   - `solucao.md` — passo a passo técnico com comandos, resultados e evidências.  
   - `imagem/` — capturas de tela ou outros artefatos relevantes (se houver).

---

## Observações

- Este repositório é **dinâmico**: novos desafios serão adicionados à medida que eu for estudando e resolvendo.  
- A ideia é mostrar **progressão prática**, metodologia de resolução e documentação consistente, sem depender de teoria apenas.  
- Cada desafio está estruturado para que qualquer pessoa consiga **reproduzir os passos** e ver a lógica da resolução.
